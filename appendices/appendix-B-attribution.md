This appendix defines how the **Global Safety Standard (GSS by ACL)** must be credited, referenced, and preserved across all uses, forks, and derivative works.

## 1. Canonical Attribution

Any system, publication, product, dataset, or framework that uses or claims compatibility with this standard must display one of the following:

**“GSS by Applied Consciousness Lab (ACL)”**  
or  
**“GSS by ACL”**

No other attribution format is considered canonical.

Attribution must be visible in:

• Documentation  
• User interfaces  
• Source code headers  
• Research papers  
• Websites  
• Products  
• Marketing materials  
• Academic citations  
• Derivative frameworks  

If GSS by ACL is used, its origin must be visible.
