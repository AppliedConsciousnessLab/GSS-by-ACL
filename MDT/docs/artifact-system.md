# MDT Artifact System

Every client receives a structured set of artifacts designed to support reflection, practice, and development.

## Artifact index

| Artifact ID | Artifact | Purpose |
| --- | --- | --- |
| MDT-001 | Executive Summary | High-level overview of strengths, patterns, and next steps |
| MDT-002 | Face Analysis | Observational review of facial features and patterns |
| MDT-003 | Ear Analysis | Observational review of ear-related indicators and expression |
| MDT-004 | Whole Person Integration | Synthesis across body, behavior, and context |
| MDT-005 | 365-Day Ascension Plan | A structured growth roadmap |
| MDT-006 | Client Dashboard | Quick summary of priorities and action items |
| MDT-007 | Practitioner Dashboard | Practitioner-facing synthesis and notes |
| MDT-008 | Image Portfolio | Visual companion set |
| MDT-009 | Quick Start Guide | Brief, actionable entry point |
| MDT-010 | References | Sources, notes, and research context |

## Design intention

The artifact system is built to be:

- structured
- reviewable
- practical
- humane
- compatible with both client and practitioner workflows

## Reporting principle

Artifacts should support reflection and action without reducing a person to a fixed label. Each artifact should be accompanied by appropriate context, confidence, and limitations where relevant.
